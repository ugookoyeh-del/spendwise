# SpendWise

A responsive personal expense tracker built with semantic HTML, CSS and vanilla JavaScript.

## Features
- Add expenses with descriptions, amounts and categories
- Live total-spend and transaction count
- Most-used category summary
- Recent expense list
- Browser persistence using localStorage
- Responsive layout and input validation

## Run
Open `index.html` in a modern browser. No build step or external dependency is required.

## Data and privacy
Expenses remain in the current browser's localStorage. Clearing browser site data removes them. This is a front-end learning project, not a bank-connected financial product.

## Roadmap
Add date filters, monthly category breakdowns, CSV export, budget limits, accessibility tests and unit tests.
